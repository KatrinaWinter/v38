<h1> Bankomat – First Java Project </h1>

<h2>About the Project</h2>
This is one of my first Java projects, developed as part of my programming studies. It is a console-based ATM simulation that allows the user to check a balance, make deposits and withdrawals, calculate interest, and view transaction history.

<h2>Features</h2>

<ul>
<li>Display the current balance</li>
<li>Deposit and withdraw money</li>
<li>Calculate interest at a fixed rate</li>
<li>Store and display transaction history during the session</li>
<li>Navigate through a menu using console input</li>
</ul>

<h2>What I Practised</h2>

<ul>
<li>Java fundamentals and program flow</li>
<li>Methods and conditional statements</li>
<li>Loops and user input using Scanner</li>
<li>Collections using ArrayList and List</li>
<li>Basic calculations and balance management</li>
<li>Creating a Git repository and pushing code to GitHub using the terminal</li>
</ul>
